# cpp-bm25-index

> RAG 检索层下沉：C++17 实现的 BM25 倒排索引内核，经 pybind11 暴露为 Python 扩展。
> 状态：**整理中**（代码与压测脚本正在陆续归档，README 先行）

## 动机

主项目的检索层原为 Python 实现，随语料增长线性劣化——3 万篇时 p95 已达 400 ms。瓶颈不在算法而在实现细节：指针跳转、内存碎片、全量排序。

于是把分词打分与倒排索引下沉为 C++17 内核，经 pybind11 暴露为 Python 扩展，**上层接口保持不变**，业务代码零改动。

## 实现要点

- **倒排索引**：词项 → posting list，连续数组存储，减少指针跳转与内存碎片
- **打分**：BM25 归一化
- **top-k**：大小为 k 的最小堆提前剪枝，避免全量排序
- **并发**：索引只读，查询侧无锁，支持多线程并发

## 验证

与 Python 原实现逐条比对：

| 项目 | 结果 |
| --- | --- |
| top-10 结果一致率 | 100%（浮点误差 < 1e-6，并列按 doc_id 稳定排序）|
| 12 万篇规模 p95 | 148 ms → 19 ms（8 线程只读）|

## 已知局限

- 索引需全量重建，暂不支持增量更新
- 暂无磁盘持久化

这两点是下一步的优化方向。
